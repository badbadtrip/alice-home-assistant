# Проверка экспериментальной версии 0.1.1

Статус: experimental. Исходники опубликованы в GitHub: badbadtrip/alice-home-assistant.
Отдельный стабильный релиз не заявляется.

Проверено на реальной установке Home Assistant OS с хостом amd64:

- Установка и повторная сборка штатным Supervisor при включённой защите.
- Запуск Home Functions и менеджера, создание панели и меток через API HA.
- Включение приложения в боковое меню.
- Приватный перенос двух существующих станций: MIDI и Lite 2.
- Сохранение SSH-ключа, назначений, журнала, настроек устройств и статических команд.
- Последовательная смена backend с резервом runtime; бинарники и LLM-настройки
  на колонках при переносе не менялись.
- Отключение старых менеджера, Home Functions и транспортного приложения.
- Повторный запуск нового приложения: обе станции online, ревизии синхронизированы.
- Проверка фразы для обеих станций без изменения last_triggered автоматизации.
- Запись/чтение явно названного технического события в новом журнале.
- Все 10 страниц Wiki доступны через настоящий авторизованный HA Ingress.
- LAN API отклоняет запросы без токена; прямой доступ к UI вне Ingress отклонён.
- Режим без LLM: backend-check читает каталог HA без запроса к провайдеру;
  readonly-маршруты точной фразы, освещения, таймера и fallback проверены.

Автоматические проверки:

- 6 проверок подготовки конфигурации, импорта, маршрутов и Wiki.
- 29 проверок менеджера.
- TypeScript lint/typecheck/tests в Docker-сборке.
- Go tests: telemetry, llm, home, bridge, cmd/quasar-bridge.
- Cross-build бинарника моста для Linux ARM64.
- UI suite: команды, native picker contract, медиадействия, журнал,
  desktop/mobile layout, 2/6 станций и равная высота панелей.
- SHA-256 всех 188 файлов подготовленного контекста сверены на хосте HA.
- Создана защищённая резервная копия HA с приложением и локальными исходниками;
  ошибок копирования приложения и папок нет.

Не заявляется проверенным:

- Нативная сборка контейнера приложения на хосте aarch64.
- Первая установка на чистую станцию другой прошивки/модели.
- Физический звук и микрофон после переноса: требуется проверка пользователем.
- Восстановление резервной копии на другом устройстве HA.

Для стабильного публичного релиза необходимы проверки из Wiki / Release.

## Установка из публичного репозитория

- Репозиторий добавлен в HA штатным магазином; приложение установлено из GitHub.
- Проверены запуск 0.1.0 и штатное обновление до 0.1.1.
- Проверен отдельный клон из GitHub: 187 контрольных сумм и 6 Python-тестов.
- Реестр новой установки пуст, SSH-ключ отличается от локальной установки.
- Отдельный внешний порт позволяет оставить локальную установку работающей.
- Панели экземпляров изолированы; первоначальное подключение колонок оставлено
  пользователю для ручной проверки по встроенному руководству.
