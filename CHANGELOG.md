# 0.1.3 — понятное подключение колонок

- Настройки разделены на «Колонка и звук» и «Мост».
- Пошаговый мастер показывает один текущий шаг и автоматически открывается после добавления колонки.
- Незавершённая настройка явно выделена; она не отображается как поломка связи.
- Обслуживание моста перенесено в настройки, управление звуком отделено от него.
- Убраны повторяющиеся названия голосовых команд.

# 0.1.2 — настройки медиаплеера

- Выбор медиаплеера и название сохраняются без SSH-подключения к мосту.
- Смена комнаты по-прежнему проверяется на колонке с возможностью отката.
- Исправлено удаление привязки медиаплеера.

# 0.1.1 — установка из GitHub

- Исправлены контрольные суммы исходников после клонирования Git на Linux/Windows.
- Проверены отдельный реестр и ключи при установке рядом с локальной версией.

# 0.1.0 — экспериментальная версия

- Публичный репозиторий приложений, встроенная Wiki с поиском и адаптивный UI.
- Изолированные панели для локальной и репозиторной установок.
- Home Functions, менеджер мостов, панель и Wiki в одном приложении HA.
- Изолированные данные и собственный SSH-ключ для каждой установки.
- Автоматическая подготовка панели и меток через API HA.
- Профили установки для уже получивших root-доступ MIDI и Lite 2.
- Локальный API колонок с обязательным случайным токеном.
- Резервирование, проверка отпечатка SSH и ручное подтверждение голоса.
- Новые установки без LLM передают остальные запросы штатной Алисе.
