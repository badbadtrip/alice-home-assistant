# 0.2.1 — проверка исходников после загрузки из Git

- Подготовка пакета нормализует окончания строк собственных файлов приложения до расчёта контрольных сумм.

# 0.2.0 — подключение старого моста одной кнопкой

- Переход поддерживаемого моста без архива, Git и Python: SSH-проверка, сверка файлов с исходниками приложения, резерв и переключение на новый Home Functions.
- Текущие регистрации, медиаплееры и назначения остаются на месте; остальные колонки не переключаются.
- Проверки конфигурации и сервера до изменения, откат и проверка прежнего идентификатора при ошибке запуска.
- Отдельное подтверждение голоса и кнопка возврата прежнего моста; восстановление после прерванного перехода.
- Неизвестные версии остаются заблокированными.

# 0.1.10 — переход со старого моста

# 0.1.3 — понятное подключение колонок

# 0.1.0 — экспериментальная версия

- Публичный репозиторий приложений, встроенная Wiki с поиском и адаптивный UI.
- Изолированные панели для локальной и репозиторной установок.
- Home Functions, менеджер мостов, панель и Wiki в одном приложении HA.
- Изолированные данные и собственный SSH-ключ для каждой установки.
- Автоматическая подготовка панели и меток через API HA.
- Профили установки для уже получивших root-доступ MIDI и Lite 2.
- Локальный API колонок с обязательным случайным токеном.
- Резервирование, проверка отпечатка SSH и ручное подтверждение голоса.
- Новые установки без LLM передают остальные запросы штатной Алисе.
