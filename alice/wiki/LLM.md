# LLM и маршрутизация

LLM не обязательна для точных голосовых команд. Если её настройки пустые,
обычные запросы остаются у штатной Алисы. Музыка, таймеры и другие штатные
маршруты продолжают обрабатываться по правилам моста.

Для OpenAI-совместимого Chat Completions endpoint заполните в конфигурации
приложения одновременно URL, модель и ключ. Endpoint должен быть доступен
С КОЛОНКИ: сам мост отправляет LLM-запросы. Локальный шлюз LLM устанавливается
отдельно; приложение «Алиса» не включает OmniRoute и не выдаёт подписку провайдера.

После изменения параметров новые установки получают новые значения.
Работающие мосты при обычном обновлении сохраняют собственный runtime и маршруты;
изменение конфигурации приложения не переписывает их LLM-ключи автоматически.
Для переноса endpoint существующих мостов используйте отдельную проверенную
процедуру миграции и сохраняйте возможность отката.

Ключ LLM попадёт в приватный runtime на колонке. Не включайте его в скриншоты,
Wiki, отчёты, публичные конфиги и обращения об ошибках.
