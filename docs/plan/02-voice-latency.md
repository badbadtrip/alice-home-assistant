# 2. Голосовой путь и задержка

Код: `alice/bridge/internal/bridge/native.go`, `engine.go`, `routing.go`, `progress.go`; `internal/home/functions.go`, `voice_cache.go`.

## Как идёт запрос сейчас

1. `Native.Client` получает `VoiceInput`, включает «ожидание одобрения» (`wire.EnableApproval`) и отправляет запрос в облако — облако распознаёт речь, но не отвечает, пока мост не разрешит.
2. При голосовых репликах (`VoiceCues` включены) мост ждёт финальное ASR (`EndOfUtt`) — `maybeResolve` (`native.go:564`).
3. `Engine.Decide` (`engine.go:315`): словарь голосовых фраз → повтор/сброс диалога → «скажи на кухню» → управление MA → запуск MA → имя устройства → правила маршрутизации → уточнение дома → продолжение диалога → маршрут по умолчанию (в поставке `yandex`, классификатор не вызывается).
4. Маршрут `yandex`: мост шлёт `ContinueRequest` в облако. Маршрут `home`: `Functions.handle` (см. часть 4). `llm`: `Engine.Fallback`. `playback`: MA или ретрансляция.
5. Отказ облака (`isRefusal`) переключает на LLM.

Решение по правилам — микросекунды; задержку дают сетевые вызовы на маршрутах `home`, `llm`, `playback` и ожидание финального ASR.

## Задачи

### 2.1 Временная шкала каждого запроса — **сделать первым**
- В `nativeRequest` записывать моменты: `input_at`, `asr_final_at`, `decided_at` (+ `source`), `executor_done_at`, `first_audio_at` (первый TTS-кадр к колонке) или `cloud_continue_at`.
- Писать одной строкой `slog` `native_timeline` с разностями в мс и отправлять в существующий журнал активности (`telemetry.Event`: добавить поля `asr_ms`, `decide_ms`, `exec_ms`, `speak_ms`).
- В панели «Метрики»: медиана и 90-й процентиль по маршрутам за сутки.
- **Готово, когда:** для любого запроса видно, где ушло время; есть цифры «до» для задач 2.2–4.x.

### 2.2 Не ждать финального ASR для очевидных команд
- Сейчас при `VoiceCues` решение ждёт `EndOfUtt`. Облако присылает промежуточные гипотезы; для точной фразы словаря или точной команды плеера («пауза», «дальше») можно начинать по стабильной частичной гипотезе.
- Осторожно: «включи свет» → «включи свет на кухне». Начинать раньше только при совпадении целой фразы из словаря, у которой нет продолжений в словаре (префикс другой фразы — ждать).
- **Проверка:** временная шкала, `asr_ms` для таких команд.

### 2.3 Прогресс-реплики только когда реально долго
- `progressAfter(p, 900ms)` для дома и `local_progress.after_ms=2000` в поставке. После 4.1/4.3 команда дома должна укладываться в 300–500 мс — реплика «секунду» для дома станет не нужна; оставить только для LLM.

### 2.4 Классификатор не в горячем пути
- В поставке `default_route: yandex` (`alice/bridge-config.json`), но `config.example.json` и `DefaultRoutingConfig()` (`routing.go:67`) по умолчанию `classify` с таймаутом 8 с. Если таблица маршрутов не дошла до колонки, каждый нераспознанный запрос ждёт LLM.
- Сделать `yandex` значением по умолчанию в коде и примере; классификатор — только по явной настройке.

### 2.5 Один решатель вместо цепочки проверок
- `Decide` — 12 последовательных проверок с разными источниками (словарь, имена, правила, MA, ретрансляция). Порядок неочевиден и уже давал ошибки («включи кино»).
- Свести в таблицу: каждая проверка — `func(text) (RouteDecision, bool)` в явном списке с приоритетом, тестом на каждую строку и строкой в `native_timeline` о том, какая сработала.
