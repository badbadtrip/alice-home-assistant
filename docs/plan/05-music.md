# 5. Музыка: Music Assistant

Код: `alice/music/sendspin_service.py`, `alice/server/src/sendspin.ts`, мост `internal/sendspin/player.go`, `cmd/quasar-bridge/sendspin.go`; менеджер `_ma_track`, `_ma_entity` в `service.py`; панель `_nowPill`.

## Сейчас

- Звук: MA → Sendspin → music (Python) → HTTP-поток кадров через HF → мост → `station-pcm` → ALSA. Работает, задержка старта ~2,4 с (замер 0.58.3).
- Поиск и запуск: music вызывает HA-сервисы `music_assistant.search`, `get_library`, `play_media` через REST HA; своё ранжирование (`pick`, `by_artist`, `stem`). Лучшие треки — прямой API MA по токену (0.58.9).
- Трек на карточке: менеджер ищет HA-сущность MA по шаблону производитель+имя, читает её состояние; панель следит за `hass.states`.

## Задачи

### 5.1 Один клиент к MA — его собственный API
- MA имеет WebSocket/HTTP API с поиском, очередями, `top_tracks`, radio, избранным и событиями плеера. Сейчас половина через HA (лишний прыжок и ограниченный набор), половина напрямую.
- Перейти на прямой API для всего: `music/search`, `player_queues/play_media`, `music/artists/top_tracks`, `music/favorites`. HA-путь оставить запасным, если токена нет.
- Токен: сейчас вводится вручную в опциях. Изучить получение без пользователя (MA выдаёт токен HA-интеграции при discovery; проверить, можно ли приложению получить свой через Supervisor discovery). Если нельзя — подсказка в панели «Музыка» с полем токена вместо опций приложения.

### 5.2 Трек от первоисточника
- music уже получает `metadata` по Sendspin (`on_metadata`: title, artist, album, artwork_url, progress). Отдавать это мосту кадром `M` вместе со звуком → мост кладёт в `now_playing` → карточка без поиска HA-сущности и без шаблона.
- Убрать `_ma_entity`/`_ma_track` из менеджера и `_nowPill`-подмену в панели после перехода.
- Обложка: `artwork_url` MA (LAN http) отдавать через HF-прокси `/sendspin/artwork/<speaker>` — панель грузит по Ingress.

### 5.3 Меньше своего ранжирования
- `pick`/`stem`/`split_artist` — своя эвристика поверх поиска MA. С прямым API MA поиск уже ранжирован; оставить только фильтр «исполнитель совпадает» и «свой плейлист раньше чужого».
- Перенести разбор фраз «песню X группы Y» в одно место (сейчас частично в Go `playback.Search`, частично в Python `split_artist`).

### 5.4 Задержка старта
- 2,4 с из них ~2,3 с — сам MA (`play_media`). Проверить по API: `player_queues/play_media` с `option=replace` и одним треком, буфер Sendspin (`BUFFER_CAPACITY`), предзагрузку. Замер по временной шкале (2.1, `exec_ms` для `ma_play`).

### 5.5 Звук
- Миди: 48 кГц ресемплируется в 96 кГц `speexrate_medium`, стерео дублируется в 4 канала (`softvol → plug → dmix`). Проверить, принимает ли helper 96 кГц напрямую (MA умеет отдавать нужную частоту по Sendspin `supported_formats`) — заявлять 96 кГц и убрать ресемплинг на колонке.
- Ждём от пользователя описание проблемы со звуком.
