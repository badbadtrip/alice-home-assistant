# 6. Менеджер, состояние колонок, панель

Код: `alice/manager/service.py` (1707 строк), `admin.py`, `updater.py`, `proxy.py`; `alice/app/gateway.py`; `alice/ui/alice-voice-card.js` (410 КБ, 1860 очень длинных строк).

## Цепочка состояния сейчас

1. Мост раз в секунду сравнивает своё состояние и при изменении (или раз в 15 с) шлёт `POST /now-playing` в HF (`state_report.go`).
2. HF держит последнее в памяти.
3. Менеджер раз в секунду: `monitor_cycle` (читает HF `/now-playing`, для старых мостов опрашивает `/healthz`), `airplay_cycle`, `updater.cycle` — всё в одном потоке.
4. Панель ждёт `/api/speakers-wait/<rev>` (long-poll до 12 с) и раз в 30 с полностью перечитывает.
5. При каждом `GET /api/speakers` менеджер ещё раз читает HF `/now-playing` (`_fresh_now_playing`) и, для MA, HA.

## Задачи

### 6.1 Состояние — событием
- Мост шлёт состояние сразу менеджеру (тот же токен), менеджер будит ожидающих `state_cond.notify_all()`. Опрос HF раз в секунду и `_fresh_now_playing` убрать. HF перестаёт хранить состояние колонок, которое ему не нужно.
- Альтернатива меньшего объёма: HF сам будит менеджер (HTTP-хук) при `POST /now-playing`.
- **Готово, когда:** смена громкости/трека видна в панели < 300 мс, без опросов раз в секунду.

### 6.2 Разделить монитор
- Один поток делает здоровье колонок, AirPlay и автообновление мостов; медленный SSH одной колонки задерживает остальное. Отдельные потоки/таймеры на каждую задачу, ограничение параллельности SSH на колонку.

### 6.3 Панель: модули и ресурсы
- 410 КБ одного файла, внутри картинки моделей. Разделить: API-клиент, состояние, карточки колонок, редактор фраз, музыка, настройки, сервис, картинки — отдельными файлами (без сборщика: ES-модули через Ingress или простой `build.mjs`, как у сервера).
- Картинки — отдельными файлами с кэшированием.
- Не менять внешний вид; цель — читаемость и скорость загрузки.

### 6.4 Меньше `hass.states` в панели
- После 5.2 трек приходит с колонки — подмена из `hass.states` не нужна. Оставить HA только для штатной Яндекс.Музыки (она видна только через `media_player`).

### 6.5 Менеджер: разрезать `service.py`
- 1707 строк: реестр, SSH, установка, мониторинг, история метрик, HTTP-обработчики. Разделить по модулям без изменения поведения; тесты уже есть (`tests/test_manager.py`).
