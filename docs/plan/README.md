# План улучшений «Алиса для Home Assistant»

Составлен 2026-11-13 по коду версии 0.58.9 (ветка `claude/sendspin-player`, затем `main`).
Заменяет устаревший `DEVELOPMENT-PLAN.md` (0.9.0) в части скорости, подсветки и упрощения.

## Принципы

1. **Проще.** Меньше слоёв, процессов, сетевых прыжков и своих форматов. Удаляем код, который дублирует чужой.
2. **Прозрачнее.** Каждый голосовой запрос оставляет короткую временную шкалу: что услышали, кто решил, сколько заняло каждое звено. Подсветка пишет, почему сменила вид.
3. **Первоисточник.** Данные берём у того, кто их знает: состояние устройства — из события HA, трек — из Music Assistant, громкость — из микшера колонки, состояние Алисы — из её сокета 9875. Не опрашиваем то, на что можно подписаться, и не храним копию там, где можно спросить источник.
4. **Не изобретаем велосипед.** Если HA, Music Assistant или прошивка уже умеют — используем их (HA Assist intents, MA queue/radio, события `state_changed`), а своё оставляем только там, где готового нет.
5. **Сначала замер, потом правка.** Каждое ускорение подтверждается цифрами «до/после» из той же временной шкалы.

## Порядок работ

Этапы идут по ценности для пользователя; внутри этапа задачи независимы.

**Этап A — измерить (1–2 дня).** Без этого остальное вслепую.
- 2.1 Временная шкала запроса на мосту.
- 3.1 Журнал смен вида подсветки.
- 8.2 Уровень логов приложения: убрать TRACE.

**Этап B — быстрые победы (2–4 дня).**
- 4.1 Один вызов `/execute` вместо `GET /functions` ×2 + `/resolve` + `POST /functions`.
- 4.2 Кэш устройств по событиям реестра, без пересборки на каждую команду.
- 4.3 Ответ «готово» сразу по `state_changed`, без опроса 100 мс до 2 с.
- 3.2–3.4 Устранить известные причины моргания.

**Этап C — первоисточники (4–7 дней).**
- 4.4 HA Assist (`conversation/process`) как основной локальный разборщик команд умного дома, наш разбор — запасной.
- 5.1 Прямой API Music Assistant (WebSocket) вместо HA-сервисов для поиска/очереди; трек и обложка — от MA.
- 6.1 Колонка шлёт состояние напрямую менеджеру событием, без опроса HF раз в секунду.

**Этап D — упрощение кода (по ходу, 5–10 дней).**
- 7.x Разрезать `main.go`, убрать неиспользуемые режимы и флаги.
- 6.3 Разделить `alice-voice-card.js` (410 КБ, 1860 строк) на модули и картинки.
- 8.1 Одна копия CHANGELOG/wiki, манифест генерируется.

## Как вести этот план

- У каждой задачи есть номер (например, 4.1). В коммитах и CHANGELOG ссылаться на номер.
- Статус ставить в таблице «Статус» внизу файла части: `план`, `в работе`, `готово (версия)`, `отменено (почему)`.
- Если замер опроверг гипотезу — пишем это в файле части, а не удаляем пункт.
- Проверки на колонках: по одной станции, с резервом, голосовую проверку подтверждает пользователь (см. `AGENTS.md`).
