# Безопасность и данные

- Web UI работает через HA Ingress. API менеджера дополнительно проверяет
  токен текущего пользователя HA и требует права администратора.
- Приватный Supervisor token доступен серверным процессам и не передаётся
  браузеру или колонкам. Доступ к HA API нужен для чтения состояний, выполнения
  действий и регистрации панели/меток.
- Менеджер слушает только loopback внутри приложения. Ingress gateway принимает
  подключения от Supervisor. Прямого внешнего порта управления нет.
- LAN-порт Home Functions защищён отдельным случайным токеном. Используйте его
  только в доверенной сети; HTTP не шифрует LAN-трафик. Не пробрасывайте порт наружу.
- Каждая установка создаёт свой SSH-ключ. Колонки доверяют только явно добавленному
  публичному ключу; SSH-серверы проверяются по сохранённому отпечатку.
- Раздел «Управление» разрешает администратору явно выполнять root-команды на доверенной колонке и редактировать текстовые файлы. Другие пользователи не получают доступа. Результаты команд и содержимое файлов могут содержать секреты; они не записываются в журнал менеджера. Консоль ограничивает время и объём вывода, но не ограничивает полномочия root.
- Журнал ограничен метаданными последних команд; аудио и полные ответы LLM в него
  не входят. Фразы могут содержать личную информацию — учитывайте это при передаче логов.
- `/data` и резервные копии содержат секреты. Не загружайте их в GitHub Wiki.

Для сообщения об ошибке достаточно версии приложения, модели/профиля, версии
прошивки, шага ошибки и обезличенного сообщения. Не прикладывайте runtime.env,
приватный SSH-ключ, токены, полную конфигурацию провайдера или персональные логи.
